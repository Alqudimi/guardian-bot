## 2026-08-22 — Mobile review

تمت مراجعة `/` و`/content` على viewport بعرض 390px. تظهر الصفحة الرئيسية ضمن عمود واحد قابل للقراءة، مع بطاقات التشغيل والحالات غير المتاحة دون بيانات مصطنعة. لقطة الصفحة الكاملة أخفت الشريط الجانبي الثابت كما تفعل أداة الفحص، لذلك بدت `/content` مزاحة. تحقق viewport الفعلي أظهر أن صفحة القواعد قابلة للقراءة ضمن عرض الهاتف، مع حقل Group ID وزر الفتح وحالة البداية. لا يوجد قص أفقي في viewport الفعلي.

تمت مراجعة `/runbook` على سطح المكتب. تظهر خريطة التفويض ومصفوفة الأدوار وخطوات staging/production وحالات التدهور في هيكل واضح ومقروء. يظل الشريط الجانبي خارج لقطة الصفحة الكاملة لأنه ثابت، بينما المحتوى الأساسي لا يعتمد عليه لفهم الدليل.
